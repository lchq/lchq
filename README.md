# 🚂 运费报价查询系统 v4.0

## 功能特性

### 客户查价端
- 🔍 模糊搜索省市名（输入"新"即可匹配"新疆""内蒙古"）
- 🚂 火车标识，展示每种车型的报价和吨位
- ⭐ 自动标注每吨单价最低的车型
- 📋 一键复制链接 / 🔗 二维码弹窗 / 💬 微信转发

### 管理后台
- 🔐 密码登录（默认密码：admin123）
- ➕ 新增/编辑/删除省市和车型
- 📋 操作日志记录每次增删改
- ⬇️ 导出数据备份（JSON文件）
- ⬆️ 导入数据备份（恢复数据）
- 🔄 恢复为默认示例数据

## 部署步骤（GitHub Pages）

### 1. 准备工作
- 注册 GitHub 账号：https://github.com
- 记住你的用户名（会出现在网址里）

### 2. 创建仓库
- 点右上角 `+` → `New repository`
- Repository name 填：`freight-price`（或任意名称）
- 选 **Public**
- 勾选 **Add a README file**
- 点 **Create repository**

### 3. 上传文件
- 进仓库 → `Add file` → `Upload files`
- 把 `freight-v4.0.html` 拖进去
- **重要**：上传后点文件名 → 重命名为 `index.html`（全小写）
- Commit message 写：添加查价页
- 点 **Commit changes**

### 4. 开启 GitHub Pages
- 仓库顶部 → `Settings` → 左侧找到 `Pages`
- Source 选 `Deploy from a branch`
- Branch 选 `main`，目录选 `/ (root)`
- 点 **Save**
- 等待 1-2 分钟

### 5. 访问
- 浏览器打开：`https://你的用户名.github.io/仓库名/`
- 强制刷新：`Ctrl + Shift + R`

## 管理后台使用

### 进入管理端
连续点击页面右下角 `v4.0 🚂` 5次 → 弹出密码框 → 输入密码（默认 `admin123`）

### 修改管理密码
用记事本打开 `freight-v4.0.html`，搜索这行：
```
const ADMIN_PASSWORD = "admin123";
```
把 `admin123` 改成你自己的密码，保存后重新上传。

### 录入价格
1. 进管理后台 → 点 `＋ 新增省市`
2. 填省市名称（如：北京）
3. 填车型名称（如：整车）、价格、吨位
4. 点 `＋ 添加车型` 可加更多车型
5. 点 `💾 保存`

### 数据备份
- 每次改完价格 → 点 `⬇️ 导出备份` → 下载 JSON 文件存好
- 换电脑/清缓存后 → 点 `⬆️ 导入备份` → 选备份文件恢复

## 常见问题

### Q: 页面打开是空白/404？
- 确认文件已重命名为 `index.html`（全小写）
- 确认文件在仓库根目录（不在子文件夹里）
- 确认 Settings → Pages → Folder 是 `/ (root)`
- 等 2 分钟后再刷新

### Q: 改了价格但客户看不到？
- 让客户强制刷新：`Ctrl + Shift + R`
- 或等几分钟（GitHub Pages 有缓存延迟）

### Q: 换电脑后数据没了？
- 这是正常的，数据存在浏览器本地
- 用 `⬇️ 导出备份` 功能提前备份
- 换设备后用 `⬆️ 导入备份` 恢复

## 技术说明

- 纯前端单文件，无需服务器、数据库
- 数据存储在浏览器 localStorage
- 适配手机微信内置浏览器
- 零依赖，不引用任何外部 JS/CSS 库
- 二维码通过 qrserver.com API 生成

## 升级建议

如果需要多设备实时同步数据，可以考虑：
- Cloudflare Workers + KV 存储（免费额度够用）
- 阿里云 OSS 静态托管（国内访问更快）
- 腾讯云 COS + CDN（企业级稳定）
